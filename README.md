# BASHARATYAN V: unofficial website concept

Static HTML/CSS/JS. Serve this folder with any local HTTP server. No build dependencies. Native progressive enhancement: manual image transitions and editable WhatsApp draft; official store handles products, inventory and purchases. No analytics or third-party scripts.

Photography, logo, fabric swatches and48.9s collection film originate from the official BASHARATYAN V site. No generated imagery. Raster provenance is embedded or in sidecars. Cormorant Garamond and Golos fonts use OFL licences included in fonts/.

This concept is not the official brand website.
